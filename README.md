# Python Searching

## Explanation

Searching is the process of finding a particular element in a collection of data.

This program demonstrates **Linear Search**, where each element is checked one by one until the required element is found.

## Problem Statement

Write a Python program to search for an element in a list using Linear Search.

The program should display the position of the element if it is found.

## Features

* Uses Linear Search
* Accepts a list of numbers
* Searches for a specified element
* Displays the position of the element
* Handles elements that are not present

## How It Works

1. The user enters the number of elements.
2. The elements are stored in a list.
3. The user enters the element to search.
4. Each element is compared with the search element.
5. If a match is found, its position is displayed.
6. If no match is found, an appropriate message is displayed.

## Technologies Used

* Python 3

## Data Structure Used

* List

## Methods Used

* `input()`
* `append()`
* `range()`

## Program Flow

1. Read the number of elements.
2. Create an empty list.
3. Read and store the elements.
4. Read the search element.
5. Traverse the list.
6. Compare each element with the search element.
7. Display the position if found.
8. Otherwise, display "Element not found".

## Sample Input

```text
Enter the number of elements: 5
Enter element 1: 10
Enter element 2: 20
Enter element 3: 30
Enter element 4: 40
Enter element 5: 50
Enter the element to search: 30
```

## Sample Output

```text
Element found at position: 3
```
